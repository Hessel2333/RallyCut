# 架构与不变量

`src/App.tsx` 是中文桌面编辑工作区；`timeline.ts` 管理整数时间映射；`jobs.ts` 对照当前标记与预设显示快照失效状态和由实际速度估算的剩余时间。视频通过 Tauri asset protocol 流式访问，前端不读取视频本体。

Rust 模块：

| 文件 | 职责 |
| --- | --- |
| `model.rs` | Asset / Session / Match / Preset / Job，微秒区间、排序变更校验、文件名清理 |
| `media.rs` | 工具发现、完整 ffprobe JSON、自然排序、流式哈希与读回复制、无覆盖提交 |
| `store.rs` | SQLite WAL、事务化迁移、持久化 JSON 类型记录、启动时中断任务恢复 |
| `engine.rs` | 任务快照指纹、参数数组、取消子进程、真实进度、导出和验证 |
| `preview.rs` | 按内容哈希缓存的代理和缩略图；明确的原片时长/偏移映射 |
| `lib.rs` | 受控 IPC、原生对话框授权、动态精确文件访问范围、单消费者队列 |

SQLite 使用 `records(kind,id,json)` 保存版本化模型，`migrations` 与 `PRAGMA user_version` 管理迁移。当前 schema 版本为 1。未来比当前更新的 schema 会被拒绝，避免降级破坏数据。未采用 SQL 插件向前端开放 SQL。

## 时间和内容身份

- 所有区间为 `[start_us,end_us)`，微秒用 i64；ffprobe 的原始 `time_base`、`avg_frame_rate`、流时间戳和 `duration_ts` 完整保留。
- 时长优先通过 i128 中间乘除从整数 tick/time_base 得出，最后仅在微秒精度截断。FFmpeg 使用源有理数帧率，60000/1001 不转换为 60。
- 拍摄保存有序 asset ID；比赛保存一个或多个源范围。前后端均验证边界，后端还验证范围按拍摄顺序连续。有标记后重排被明确拒绝。
- Asset UUID 是稳定引用；原路径与工作路径分别保存。兼容字段 `sha256` 存放复制素材的完整 SHA-256，或以 `sample-v1-` 开头的本地引用抽样标识（文件大小及首/中/尾各最多 64KiB）。抽样只辅助识别，不保证完整性；引用去重还要求相同路径。旧记录和任务快照不自动迁移。
- ExportJob 独立保存比赛、素材和预设快照；内容指纹来自 SHA-256 + 区间 + 预设。任务完成后不会因编辑标记而自动重做；当前 UI 显示与当前配置不符的任务。尚未自动复用旧输出。

## 导出路径

1. 串行消费者从 SQLite 取 waiting 任务，按素材记录的方法检查完整哈希或有限样本及参数；新版本地引用不会整文件扫描。自动模式先实测硬件编码。
2. 每个输入使用参数数组传入 `-ss`，由 FFmpeg 精确寻址解码。视频 `trim` + `setpts`，缩放/补边、像素格式、SAR 与输出帧率统一。
3. 音频采用首条音轨，`atrim`、48kHz/stereo 重采样及时间戳处理，缺失/过短则静音补齐至视频区间长度。
4. `concat` 滤镜拼接各段，最终 H.264/AAC 编码一次，输出带任务 ID 的 `.partial.mp4`。不使用路径 concat 清单或 shell 字符串。
5. ffprobe 校验视频时长、尺寸与编码；对首尾和每个源交界抽样解码。UI 明确称为基本+抽样检查，不声称完整验证。
6. 同目录、不覆盖地提交正式名称。Windows 使用 `MoveFileExW` 且不传 REPLACE_EXISTING / COPY_ALLOWED；非 Windows fallback 使用同卷硬链接提交（未实测其他平台）。

FFmpeg 的舍入受实际帧率和采样率约束；预览播放器不构成逐帧编辑保证。缺失拍摄内容不自动补画面，文件边界始终可见。

## 生命周期与权限

重编码每次一个任务；暂停只暂停后续启动。取消终止原生进程并等待回收，清理该任务自己的临时路径。正常关闭时先停止后续任务并取消活动任务；异常退出后，非终态导出变为 interrupted，允许整局重试。已完成结果保持不变。排队暂停状态持久化。

慢 I/O、复制、hash、ffprobe、代理均在 Rust 工作线程；FFmpeg 日志有大小上限。复制按文件串行。导入已完成素材立即入库；未完成拍摄可再次导入并复用已验证素材，未实现导入任务本身的持久化进度。

窗口 capability 仅 `core:default`，未开放 shell、通用文件读写或 SQL。原生文件对话框记录授权路径，asset scope 初始为空，只动态允许已导入素材与生成缓存的精确文件。正式构建 CSP 限制本地 IPC/asset。无远程 API、账号、遥测。
